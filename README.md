# Raiz Natural

## Funcionalidades implementadas
Se desarrolló y mejoró el sitio web, agregando persistencia de datos, autenticación de usuarios, gestión interna de solicitudes, integración con APIs y envío de correos electrónicos. Además, se realizó la configuración necesaria para su despliegue en Render, utilizando PostgreSQL como base de datos.  

API utilizada: [DolarAPI](https://dolarapi.com/docs/argentina/operations/get-dolar-oficial.html), especificamente  https://dolarapi.com/v1/dolares/oficial  
Repositorio: https://github.com/Tomig02/web-2-parcial-2
Despliegue: https://web-2-parcial-2.onrender.com/
